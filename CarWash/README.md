# Automatic Car Wash PLC Project

## Overview
An automatic car wash control system developed in Siemens TIA Portal.

## Hardware & Software
- PLC: Siemens S7-1200
- IDE: TIA Portal V19
- Language: LAD

## Architecture
- FB_Doors – automatic door control
- FB_Foam – foam pump control
- FB_Brushes – washing brush control
- FB_Water – water system control
- FB_Dryer – drying system control
- FB_Wax – wax application control
- FB_Sequencer – main washing sequence management
- Instance DBs – individual function block data storage

## Features
- Automatic car detection
- Automatic door control
- Sequential washing process
- Foam application
- Brush washing
- Water rinsing
- Vehicle drying
- Wax application
- State machine
- P_TRIG edge detection
- TON timers
- Modular FB-based architecture
